■ ② 国土地理院の空中写真版（同じ向き・同じ処理）
    置杵牛_空中写真_A4縦_線なし.jpg / 置杵牛_空中写真_A4縦_点線あり.jpg
    置杵牛_空中写真_A4横_線なし.jpg / 置杵牛_空中写真_A4横_点線あり.jpg
  ・細かさは衛星よりずっと上です（元が約1.7m／画素。衛星は10m／画素）。
  ・ただし、置杵牛のあたりの空中写真は、撮影した年も季節も違う写真のつなぎ合わせです
    （国土地理院の「全国最新写真」は、場所ごとに一番新しい写真をつないで作られています）。
    そのため谷の中に、秋の金色、夏の緑、白っぽく写った区画などが四角く並びます。
    明るさの幅は整えましたが、継ぎ目には手を入れていません。
    色を合わせることはある程度できますが、季節の違い（木の色、畑の状態）までは消せません。
  ・使い分けの案：表紙や大扉のような全景は衛星、本文で集落のあたりを大きく見せるなら
    空中写真（1枚の写真に収まる範囲なら継ぎ目が出ません）。

■ ③ 置杵牛の行政区のデータ（町丁・字等別境界）
  ・e-Stat から直接ダウンロードできます（美瑛町ぶん・Shapefile・緯度経度）：
    https://www.e-stat.go.jp/gis/statmap-search/data?dlserveyId=A002005212020&code=01459&coordSys=1&format=shape&downloadType=5
    （画面から行く場合：e-Stat → 地図（統計GIS）→ 境界データダウンロード → 小地域 → 国勢調査
      → 2020年 → 小地域（町丁・字等別） → 世界測地系緯度経度・Shapefile → 北海道 → 美瑛町）
  ・中身は r2ka01459.shp ほか。美瑛町の字がすべて入っていて、置杵牛は S_NAME が「字置杵牛」
    （KEY_CODE 014590320）の1つです。
  ・QGISでの読み込み：レイヤ → レイヤを追加 → ベクタレイヤを追加 → .shp を指定。
    文字化けしたら、レイヤのプロパティ → ソース → データソースのエンコーディングを「Shift_JIS」に。
    置杵牛だけにするには、フィルタに  "S_NAME" = '字置杵牛'  と入れます。
  ・置杵牛だけを切り出したファイルも入れました：置杵牛_行政区.geojson（そのままQGISで開けます）
  ・出典の例：「令和2年国勢調査 町丁・字等別境界データ」（総務省統計局）を加工して作成

■ 出典
  衛星：欧州宇宙機関 Copernicus Sentinel-2 のデータを加工して作成
  空中写真：国土地理院（地理院タイル 全国最新写真・シームレス）を加工して作成
  行政区：「令和2年国勢調査 町丁・字等別境界データ」（総務省統計局）を加工して作成
